Baseline reference

Mean-One Weightings for the Velocity Objective

Closed-form, mean-one baseline weights under uniform timestep sampling. PW-C and PW-S are excluded.

Convention

Noise-to-data time: \(t=0\) is noise and \(t=1\) is data, with \(t\sim\mathcal U(0,1)\).

\[ \mathcal L_v = \mathbb E_{t\sim\mathcal U(0,1)} \left[ \bar w(t)\, \left\|v_\theta(x_t,t)-v^\star(x_t,t)\right\|_2^2 \right], \qquad \int_0^1 \bar w(t)\,dt=1. \]

Uniform Flow Matching

Reference
\[ \boxed{\bar w_{\mathrm{FM}}(t)=1} \]

SNR Weighting

Late emphasis
\[ \boxed{\bar w_{\mathrm{SNR}}(t)=3t^2} \]

Source: Gagneux et al., Training Flow Matching

Kingma–Gao Sigmoid Monotonic

ELBO-motivated monotonic
\[ \boxed{ \bar w_{\mathrm{KG}}(t) = \frac{1}{Z_{\mathrm{KG}}} \frac{2t(1-t)} {(1-t)^2+e^{-2}t^2} } \] \[ Z_{\mathrm{KG}} = \int_0^1 \frac{2t(1-t)} {(1-t)^2+e^{-2}t^2}\,dt \approx 1.373260287. \]

Configuration: \(w(\lambda)=\operatorname{sigmoid}(-\lambda+2)\), \(\lambda(t)=2\log\frac{t}{1-t}\).

Source: Kingma & Gao, Understanding Diffusion Objectives as the ELBO with Simple Data Augmentation

Min-SNR-\(\gamma\)

Clamped SNR
\[ \boxed{ \bar w_{\mathrm{MinSNR}}(t;\gamma) = \frac{3(1+\sqrt{\gamma})^2}{\gamma} \min\!\left\{t^2,\gamma(1-t)^2\right\} } \]

Default: \(\gamma=5\).

Source: Hang et al., Efficient Diffusion Training via Min-SNR

SD3 Logit-Normal

Mid emphasis
\[ \boxed{ \bar w_{\mathrm{LN}}(t;m,s) = \frac{ \exp\!\left[ -\frac{\left(\operatorname{logit}(t)-m\right)^2}{2s^2} \right] }{ s\sqrt{2\pi}\,t(1-t) } } \]

SD3 default comparator: \(m=0,\;s=1\).

Source: Esser et al., Stable Diffusion 3

SD3 CosMap

Symmetric bump
\[ \boxed{ \bar w_{\mathrm{CosMap}}(t) = \frac{2}{ \pi\left(1-2t+2t^2\right) } } \]

Source: Esser et al., Stable Diffusion 3

RF++ U-Shaped Weighting

Endpoint emphasis
\[ \boxed{ \bar w_{\mathrm{RF++}}(t;a) = \frac{a}{ 2(e^a-1) } \left[ e^{at}+e^{a(1-t)} \right] } \]

RF++ setting: \(a=4\). Equivalent form: \(\bar w(t)=2\cosh(4(t-\tfrac12))/\sinh(2)\).

Source: Lee et al., Improving the Training of Rectified Flows
